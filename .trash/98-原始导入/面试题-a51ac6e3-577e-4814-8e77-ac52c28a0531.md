## 题目 1

Agent系统面临的安全威胁有哪些？

### 知识点

- 分类：安全、AI Agent
- Prompt Injection直接注入
- Prompt Injection间接注入
- 工具滥用
- 数据泄漏
- 权限提升

### 答案

主要威胁包括四类：Prompt Injection（分直接注入和间接注入）、工具滥用、数据泄漏和权限提升。直接注入是用户在输入中加入恶意指令，间接注入是从外部数据源（如网页、文档）读取恶意内容，不同类型攻击的防御位置不同。

### 解析

考查对Agent系统安全威胁的整体认知和分类理解。

## 题目 2

间接Prompt Injection怎么防？

### 知识点

- 分类：安全、AI Agent
- 外部内容不可信处理
- 标签隔离
- 系统指令与数据输入分离
- 高风险工具二次确认

### 答案

不能只在用户输入层过滤，从网页、文档、API等外部来源获取的内容要当不可信数据处理。具体措施包括：对外部内容做标签隔离，明确区分系统指令和数据输入；高风险工具调用前要求二次确认，而不是直接执行。

### 解析

考查对间接注入攻击的防御策略，理解外部数据源的风险。

## 题目 3

Agent怎么避免把敏感信息泄漏给工具？

### 知识点

- 分类：安全、AI Agent
- 工具入参最小化
- 上下文不整体传递
- 敏感字段引用ID化

### 答案

工具入参要做最小化处理，不要把整段上下文传给第三方工具。用户身份、密钥和个人信息不能直接出现在工具调用参数里。敏感字段要用引用ID而不是明文传递，避免直接暴露用户隐私数据。

### 解析

考查敏感信息保护意识，理解最小权限和脱敏原则。

## 题目 4

Agent被诱导执行危险操作怎么设防？

### 知识点

- 分类：安全、AI Agent
- 高风险操作独立确认机制
- 不依赖模型自判断
- 工具层强制审批流程

### 答案

高风险操作（如删除文件、转账、发送消息）要有独立的确认机制，不依赖模型自己判断。必须在工具层强制走审批流程，即使模型被欺骗，系统层也要能拦截危险操作。

### 解析

考查纵深防御思想，危险操作不能仅靠模型判断。

## 题目 5

怎么做Agent的安全测试？

### 知识点

- 分类：安全、AI Agent、测试
- Prompt Injection样本构造
- 全量访问样本
- 异常工具调用样本
- 工具调用行为验证
- 回归级别测试

### 答案

要构造Prompt Injection样本，包括全量访问样本和异常工具调用样本。测试不能只看输出文字，还要验证工具是否被不当调用。安全测试要进入回归级别，每次修改Prompt或工具都要运行一遍。

### 解析

考查安全测试的完整性和持续性要求。

## 题目 6

如果Agent调用了外部API怎么防止SSRF？

### 知识点

- 分类：安全、AI Agent、系统安全
- URL参数白名单校验
- 禁止模型自由构造请求
- 统一网关出口过滤
- 请求审计

### 答案

工具调用里的URL参数要做白名单校验，不能让模型自由构造请求地址。外部API调用要走统一网关，网关负责出口过滤和请求审计，防止Agent访问内部敏感资源。

### 解析

考查SSRF攻击防护，理解模型输出不可信的防御原则。

## 题目 7

Agent的日志记录和安全审计怎么设计？

### 知识点

- 分类：安全、系统设计、监控
- 完整调用记录
- 用户身份时间戳
- 不可篡改存储
- 敏感参数脱敏
- 受控审批获取原文

### 答案

要记录每次工具调用的完整入参、出参、用户身份和时间戳。审计日志要写入不可篡改的存储。敏感参数要脱敏后再落库，排查时通过受控审批流程才能获取原文。

### 解析

考查日志审计的完整性和安全性设计。

## 题目 8

多租户Agent平台上，租户之间的安全隔离怎么做？

### 知识点

- 分类：安全、系统设计、多租户
- Tenant ID硬隔离
- 模型调用工具侧隔离
- 知识库隔离
- 日志隔离
- 数据库查询层强制过滤

### 答案

模型调用工具侧、知识库和日志都要按Tenant ID硬隔离。不能只靠Prompt的理解来区分租户数据，必须在数据库查询层和工具调用层做强制过滤，确保租户只能访问自己的数据。

### 解析

考查多租户隔离的彻底性，不能依赖应用层逻辑。

## 题目 9

怎么判断一个Agent系统的安全性已经达到生产标准？

### 知识点

- 分类：安全、AI Agent、系统设计
- 威胁建模文档
- 自动化安全回归级别
- 线上告警覆盖
- 工具调用频率监控
- 跨租户访问监控
- 高风险操作监控

### 答案

要有威胁建模文档、自动化安全回归级别和线上告警机制。告警要覆盖异常工具调用频率、跨租户访问尝试和高风险操作未经确认就执行。强调有安全测试全链路不等于安全，没有持续监控才是真正的风险。

### 解析

考查生产环境安全标准的完整评估框架。
