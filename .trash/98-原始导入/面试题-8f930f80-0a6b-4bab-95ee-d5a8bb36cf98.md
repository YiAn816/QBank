## 题目 1

什么是 AI Agent？它和传统 LLM 应用有什么区别？

### 知识点

- 分类：AI Agent、大语言模型
- 目标驱动
- 规划步骤
- 调用工具
- 使用记忆
- 反馈行动
- 单次生成到任务闭环

### 答案

AI Agent 强调目标驱动，能规划步骤、调用工具、使用记忆并根据反馈继续行动。传统 LLM 应用多是输入问题生成回答。核心区别是从单次生成变成可执行任务的闭环。

### 解析

Agent 相比传统 LLM 应用，更强调主动性和闭环执行能力。

## 题目 2

RAG 的工作流程是什么？

### 知识点

- 分类：RAG、信息检索
- 文档解析切块
- 向量化入库
- 问题向量化
- 检索相关片段
- 重排
- 模型生成回答

### 答案

RAG 的工作流程是离线把文档解析切块向量化入库，在线把问题向量化后检索相关片段，必要时重排，再让模型根据片段回答。重点是让答案有外部知识支撑。

### 解析

RAG 的核心是先检索再生成，结合外部知识库增强生成质量。

## 题目 3

LLM 幻觉问题如何缓解？

### 知识点

- 分类：大语言模型、模型优化
- RAG提供依据
- 工具查询实时数据
- 约束提示词
- 引用来源
- 答案校验
- 人工审核

### 答案

可以通过 RAG 提供依据、用工具查询实时数据、用约束提示词限制编造、再加引用来源和答案校验来缓解。高风险场景要有人审或规则兜底。幻觉不能彻底消失，只能通过工程手段降低概率。

### 解析

幻觉问题需要多种工程手段综合缓解，无法彻底消除。

## 题目 4

LangChain and Graph 这类框架的优缺点是什么？

### 知识点

- 分类：框架和工具、AI Agent
- 组件丰富
- 快速搭建
- 抽象层多
- 调试定制困难
- 核心链路可控

### 答案

优点是组件多上手快，适合快速搭建 Agent 和 RAG。缺点是抽象层多，复杂业务里调试和定制会变难。工程上可以用框架验证思路，但核心链路最好保持可控和可观测。

### 解析

框架适合快速验证，但核心业务需要保持可控性。

## 题目 5

什么是 Function Calling？在 Agent 的框架中如何落地？

### 知识点

- 分类：AI Agent、Function Calling
- 约定格式
- 选择工具
- 生成参数
- 注册Schema
- 参数校验
- 结果回填

### 答案

Function Calling 是让模型按约定格式选择工具和生成参数。落地时要先注册工具 Schema，再让模型选择调用，后端校验参数并执行，最后把结果回填给模型。关键是校验和兜底不能省。

### 解析

Function Calling 实现了模型与外部工具的交互，需要完善的参数校验机制。

## 题目 6

如何设计一个支持多轮对话的 Agent？

### 知识点

- 分类：AI Agent、多轮对话
- 保存会话状态
- 任务进度
- 必要记忆
- 上下文理解意图
- 压缩过期

### 答案

要保存会话状态、最近对话任务进度和必要记忆。每轮输入进来，先结合上下文理解意图，再决定回答、检索还是调用工具。上下文要压缩和过期，否则多轮越了越乱。

### 解析

多轮对话设计的关键是状态管理和上下文处理。

## 题目 7

Agent 记忆机制如何存储和管理？

### 知识点

- 分类：AI Agent、记忆系统
- 短期记忆
- 长期记忆
- 会话状态
- 任务状态
- 用户偏好
- 可更新删除解释

### 答案

短期记忆放当前会话和任务状态，长期记忆放稳定偏好、用户画像或历史结论。存储可以用数据库、向量库或缓存。关键是记忆要可更新、可删除、可解释，不能偷偷无限沉淀。

### 解析

记忆管理需要平衡短期和长期记忆，并确保可控性。

## 题目 8

ReAct 框架原理是什么？

### 知识点

- 分类：AI Agent、ReAct
- Reasoning加Acting
- 思考和行动结合
- 工具调用
- 结果反馈
- 最大步数控制

### 答案

ReAct 是 Reasoning 加 Acting，让模型一边思考一边决定调用什么工具。工具返回结果后，模型继续推理下一步。它适合需要外部信息的任务，但要控制最大步数。

### 解析

ReAct 通过交替推理和行动来处理复杂任务。

## 题目 9

RAG 里如何通过重排、HyDE 等方法优化准确率？

### 知识点

- 分类：RAG、检索优化
- 重排
- 结果重排序
- HyDE
- 假设答案生成
- 改善短模糊问题
- 评测数据驱动

### 答案

重排是对检索结果重新排序，把真正能回答问题的片段放前面。HyDE 是先生成一个假设答案，再用它去检索，改善用户问题太短或太模糊的情况。优化要看评测数据，不能只凭感觉。

### 解析

优化策略需要基于实际评测数据调整。

- 分类：算法、文本处理
- 文本向量化
- 余弦相似度
- 杰卡德相似度
- TF-IDF
- 阈值判断

### 答案

简单做法是先把文本转成向量，再算余弦相似度。没有模型时，也可以用杰卡德或 TF-IDF 做近似。面试里重点讲清楚输入向量化、相似度计算和阈值判断这几个步骤。

### 解析

文本相似度计算需要明确向量化、计算和判断三个环节。
