# QBank

QBank 是一个面向后端、架构与 AI 方向的中文面试题知识库，采用 Markdown 编写，适合使用 Obsidian 或其他 Markdown 编辑器阅读、整理和持续维护。

## 内容概览

- [面试题总索引](00-面试题总索引.md)：按主题快速进入题集
- `01-基础知识`：操作系统、计算机网络、数据库与 MySQL、算法与数据结构
- `02-后端与架构`：分布式与微服务、系统设计、消息队列、性能优化与运维、Redis 与缓存
- `03-AI`：大模型基础、RAG、Agent、向量数据库、NLP、微调评测、搜索推荐等
- `04-工程实践`：Python、前端、安全、测试

## 本地使用

1. 使用 Obsidian 打开本目录。
2. 从 `00-面试题总索引.md` 开始浏览。
3. 根据面试方向阅读对应题集，并在原文中补充自己的答案、案例和复习记录。

## Git 对接

本项目远程仓库地址：

```text
https://github.com/YiAn816/QBank.git
```

首次使用时执行：

```bash
git clone https://github.com/YiAn816/QBank.git
cd QBank
```

如果已经存在本地资料目录，可检查远程地址：

```bash
git remote -v
```

提交并同步更新：

```bash
git add .
git commit -m "docs: 更新面试题资料"
git pull --rebase origin main
git push origin main
```

## 内容维护建议

- 新增题集时同步更新 `00-面试题总索引.md`。
- 文件名和目录名尽量保持中文主题清晰、稳定。
- 每道题建议包含问题、结论、原理、示例和常见追问。
- 提交信息建议使用 `docs:`、`fix:` 等前缀，便于回溯变更。
